# Pocket Notes

Pocket Notes is a simple and user-friendly note-taking web application that helps users create, organize, and manage notes in one place. It is designed for quick note creation, easy grouping, and a clean writing experience.

## Project Overview

Pocket Notes allows users to create note groups and save notes inside them. Each group can represent a topic, category, subject, or personal workspace. The app is useful for managing quick thoughts, reminders, study notes, ideas, and daily tasks.

The application focuses on simplicity and ease of use. Users can create a group, select it, and start writing notes immediately.

## Features

- Create multiple note groups
- Organize notes by category or topic
- Add notes inside selected groups
- View saved notes group-wise
- Clean and minimal user interface
- Responsive layout for desktop and mobile screens
- Easy navigation between note groups
- Fast note-taking experience
- Deployed live using Vercel

## Use Cases

This project can be used for:

- Personal note-taking

Getting Started

Follow the steps below to run the project locally.

1. Clone the repository
git clone https://github.com/AKASH-18/POCKET_NOTES.git
2. Navigate to the project folder
cd POCKET_NOTES
3. Install dependencies
npm install
4. Start the development server
npm run dev
5. Open the app in your browser
http://localhost:5173
